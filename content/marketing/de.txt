Description
Prüfe Pull Requests nicht ständig selbst.

Human Turn verfolgt Reviews, CI und Coding-Agenten direkt in der Menüleiste deines Mac und zeigt dir, wann deine Aufmerksamkeit gefragt ist.

Alle verfolgten Pull Requests in einer übersichtlichen Ansicht:

- Du bist dran: Review-Anfragen, angeforderte Änderungen, fehlgeschlagene Prüfungen, fertige Agenten und Arbeit, die zum Zusammenführen bereit ist.
- Warten: Arbeit, die noch bei einem Agenten, der CI oder einem Reviewer liegt.
- Unklar: unvollständige oder mehrdeutige Signale, bei denen Human Turn keine Vermutungen anstellt.

VERBINDE DEINE ARBEIT

Verfolge Pull Requests auf GitHub, GitLab, Bitbucket Cloud und Cursor Origin. Sieh die Arbeit von Cursor Cloud Agents und GitHub Copilot zusammen mit den zugehörigen Pull Requests.

KEHRE IM RICHTIGEN MOMENT ZURÜCK

Human Turn kann dich benachrichtigen, wenn du wieder übernehmen musst, ein Agent eine Eingabe benötigt oder fehlschlägt oder ein Pull Request zum Zusammenführen bereit ist. Sinnvolle Abstände zwischen Meldungen und Einstellungen pro Repository halten Benachrichtigungen nützlich, ohne dich ständig zu unterbrechen.

BLEIB KONZENTRIERT

Pausiere ein Element für eine Stunde, bis morgen oder bis neue Commits eintreffen. Schalte Repository-Benachrichtigungen stumm, ignoriere einzelne Elemente und sortiere Arbeit nach ihrer Wartezeit. Öffne direkt den betreffenden Pull Request, die fehlgeschlagene Prüfung oder den Agentenlauf, sobald du bereit bist.

ÜBERGIB REVIEWS

Kopiere einen fertigen /review-Befehl für einen Pull Request und füge ihn in den Coding-Agenten ein, den du bereits nutzt. Human Turn startet keine Tools, ändert deinen Code nicht und verlangt keine Auswahl eines bevorzugten Agenten.

SIEH, WAS SICH GEÄNDERT HAT

Human Turn merkt sich die zuletzt von dir geöffnete Revision und zeigt an, ob neue Commits eingetroffen sind. Auf kompatiblen Macs nutzen optionale Änderungszusammenfassungen Apple Intelligence direkt auf dem Gerät. Code, Patches, Repository-Namen, Kontoidentitäten und Zugangsdaten werden nicht an einen Zusammenfassungsserver gesendet.

FÜR DIE MENÜLEISTE ENTWICKELT

Human Turn ist eine native macOS-App ohne zusätzliches Symbol im Dock. Sie aktualisiert sich dezent im Hintergrund, unterstützt die Tastaturnavigation, kann bei der Anmeldung starten und hält den aktuellen Stand deiner Arbeit griffbereit.

DATENSCHUTZ VON ANFANG AN

Human Turn läuft lokal auf deinem Mac. Zugangsdaten werden im Schlüsselbund gespeichert und nur an die von dir verbundenen Dienste gesendet, niemals an Human Turn-Server. Die App liest deine Entwicklungsaktivitäten, führt aber keine Pull Requests zusammen und verändert keine Repositories.

Human Turn erfordert macOS 14 oder neuer. Änderungszusammenfassungen mit Apple Intelligence erfordern macOS 26 oder neuer, einen geeigneten Mac sowie aktiviertes Apple Intelligence mit heruntergeladenem Modell.
