Description
Ne vérifiez plus vos pull requests en boucle.

Human Turn suit les revues, la CI et les agents de code depuis la barre des menus de votre Mac et vous indique quand votre attention est nécessaire.

Retrouvez toutes les pull requests suivies dans une vue claire :

- À vous : demandes de revue, modifications demandées, vérifications en échec, agents ayant terminé et travail prêt à fusionner.
- En attente : travail encore entre les mains d'un agent, de la CI ou d'un réviseur.
- Indéterminé : signaux incomplets ou ambigus sur lesquels Human Turn ne fait aucune supposition.

REGROUPEZ VOTRE TRAVAIL

Suivez vos pull requests sur GitHub, GitLab, Bitbucket Cloud et Cursor Origin. Retrouvez le travail des agents de code de Cursor Cloud Agents et GitHub Copilot aux côtés des pull requests concernées.

REVENEZ AU BON MOMENT

Human Turn peut vous prévenir lorsque vous devez reprendre la main, qu'un agent attend votre réponse ou échoue, ou qu'une pull request est prête à fusionner. Des délais entre les alertes et des réglages par dépôt limitent les interruptions inutiles.

GARDEZ VOTRE CONCENTRATION

Mettez un élément en attente pendant une heure, jusqu'à demain ou jusqu'à l'arrivée de nouveaux commits. Coupez les notifications de certains dépôts, ignorez des éléments et triez le travail selon son temps d'attente. Ouvrez directement la pull request, la vérification en échec ou l'exécution d'agent lorsque vous êtes prêt à intervenir.

CONFIEZ LES REVUES À VOTRE AGENT

Copiez une commande /review prête à l'emploi pour une pull request et collez-la dans l'agent de code que vous utilisez déjà. Human Turn ne lance aucun outil, ne modifie pas votre code et ne vous impose pas de choisir un agent préféré.

REPÉREZ LES CHANGEMENTS

Human Turn mémorise la révision que vous avez ouverte en dernier et indique si de nouveaux commits sont arrivés. Sur les Mac compatibles, les résumés de modifications facultatifs utilisent Apple Intelligence sur l'appareil. Aucun code, patch, nom de dépôt, identité de compte ni identifiant de connexion n'est envoyé à un serveur de résumé.

CONÇU POUR LA BARRE DES MENUS

Human Turn est une app macOS native qui n'encombre pas le Dock. Elle s'actualise discrètement en arrière-plan, permet la navigation au clavier, peut se lancer à l'ouverture de session et garde l'état de votre travail à portée de main.

LA CONFIDENTIALITÉ DÈS LA CONCEPTION

Human Turn fonctionne localement sur votre Mac. Vos identifiants sont stockés dans le trousseau et envoyés uniquement aux services que vous connectez, jamais aux serveurs de Human Turn. L'app consulte votre activité de développement sans fusionner de pull requests ni modifier vos dépôts.

Human Turn nécessite macOS 14 ou une version ultérieure. Les résumés de modifications avec Apple Intelligence nécessitent macOS 26 ou une version ultérieure, un Mac compatible et Apple Intelligence activé avec son modèle téléchargé.
